Screen Reader Access & Assistive Navigation

Guidance for accessing CivicPulse services using third-party screen reader tools

The CivicPulse Smart Governance Portal complies with World Wide Web Consortium (W3C) Web Content Accessibility Guidelines (WCAG) 2.1 Level AA and GIGW 3.0. Citizens with visual impairments can access this website using popular screen readers.

Keyboard Navigation & Shortcuts

You can navigate the portal using only your keyboard:

  • Tab: Moves focus forward to the next interactive link, input field, or button.
  • Shift + Tab: Moves focus backward to the previous interactive element.
  • Enter / Spacebar: Activates the focused button or link.
  • Escape: Closes active modal dialogs, drawers, or the Virtual Assistant panel.
  • Arrow Keys: Selects options in dropdown menus and navigates radio button groups.
