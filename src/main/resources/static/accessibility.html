Accessibility Statement

Compliance Standard: Guidelines for Indian Government Websites (GIGW 3.0) & WCAG 2.1 Level AA

Our Commitment

The CivicPulse Smart Governance Portal is committed to ensuring that its citizen grievance redressal services are accessible to all people, including persons with disabilities, regardless of technology, environment, or physical capability.

Standards & Compliance

This portal has been redesigned to conform with the Guidelines for Indian Government Websites (GIGW 3.0) and the World Wide Web Consortium (W3C) Web Content Accessibility Guidelines (WCAG) 2.1 Level AA.

Key Accessibility Features

  • Keyboard Operability: All interactive elements, forms, modal dialogs, and navigation menus can be operated completely via keyboard without a mouse.
  • Screen Reader Compatibility: The portal provides structured ARIA landmarks, logical heading hierarchies, descriptive link titles, and alternative text on informative images.
  • High Contrast Mode: An instant high-contrast toggle enables a 7:1 color contrast ratio across all modules for citizens with low vision.
  • Text Scaling: Dedicated text controls (A-, A, A+) allow text enlargement without breaking page layout or requiring horizontal scrolling.
  • Skip to Main Content: A dedicated skip link allows assistive technology users to bypass repetitive navigation bars directly to core content.
  • Trilingual Accessibility: Native linguistic support in English, Kannada (ಕನ್ನಡ), and Hindi (हिन्दी) ensures accessibility across linguistic demographics.
  • Reduced Motion: All CSS micro-interactions respect operating system prefers-reduced-motion settings.
